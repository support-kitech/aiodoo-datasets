# Preprocessing Roadmap

## v1.0.0
- Baseline Production Release.
- Stable caching.
- Synchronous processing pipeline.
- Python, XML, JSON, CSV, Markdown support.

## v1.1.0 (Planned)
- Concurrent parallel processing across multiple processes.
- Memory mapped payload reads for extreme scale datasets.
- Expanded syntax logic for SCSS and JavaScript Odoo assets.

## v2.0.0 (Long Term)
- Pluggable Generator extensions natively injecting rules into the `ProcessorRegistry`.
- Incremental AST tree-sitter integration for deep semantic relationship mapping.
